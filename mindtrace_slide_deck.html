Đặt Vấn Đề & Mục Đích Dự Án

❌ Thực Trạng Đọc Thụ Động
  • Nhanh quên kiến thức: Độc giả quên tới 80% nội dung sách/PDF sau 24h nếu không ôn tập.
  • Rào cản thuật ngữ: Các câu văn học thuật/tài chính phức tạp gây đứt quãng dòng tập trung.
  • Tài liệu tĩnh thiếu tương tác: File PDF truyền thống không thể giải thích ngữ cảnh hoặc đặt câu hỏi chủ động.
🎯 Sứ Mệnh MindTrace v2
  • Không Gian Học Tập Tương Tác: Biến file PDF tĩnh thành trải nghiệm đọc chủ động.
  • AI Giải Thích Ngữ Cảnh: Tự động làm rõ bản chất đoạn văn bôi đen và đúc kết bài học thực tế.
  • Kích Thích Active Recall: Tạo câu hỏi hồi tưởng mở để khắc sâu tri thức dài hạn.

Kỹ Thuật & Xử Lý Sự Cố

Các Lỗi Gặp Phải & Giải Pháp Thực Tế

Sự Cố Kỹ Thuật Nguyên Nhân Gốc (Root Cause) Giải Pháp Triệt Để
Báo lỗi "Không tìm thấy tài liệu" Database chưa chạy SQL migration hoặc chưa upload file. Tạo cơ chế Multi-layer Fallback: Lưu tệp Blob vào IndexedDB local + localStorage.
Đăng nhập Supabase bị ngắt trang Mặc định Supabase yêu cầu xác nhận Email trước khi vô. Cấu hình Local Demo Session Fallback trong AuthProvider để truy cập mượt mà.
AI phản hồi văn bản mẫu rập khuôn AI Fallback cũ chứa văn bản cố định về sáng tạo content. Xây dựng lại Semantic NLP Engine: Tự động phân loại rủi ro tài chính, công nghệ, tư duy.
Lỗi 404 khi Refresh trên Vercel Single Page Application bị Vercel hiểu nhầm đường dẫn. Thêm file vercel.json rewrite toàn bộ đường dẫn /(.*) về /index.html.

CI/CD & Cloud Deployment

Quy Trình Triển Khai Lên Vercel Cloud

1. Quản Lý Mã Nguồn Git & GitHub
Khởi tạo Git local, đóng gói commit sạch và đẩy toàn bộ mã nguồn lên GitHub repository: linhtranzr/Mindtracee.
2. Tự Động Hóa Vercel Deployment
Kết nối GitHub với Vercel Cloud, cấu hình Biến Môi Trường (VITE_SUPABASE_URL) và tự động re-deploy mỗi khi push code.
